# NCBI Dataformat CLI (dataformat-cli)

Installs the official NCBI Dataformat CLI utility into your devcontainer images. This tool transforms JSON-Lines metadata packages generated by NCBI Datasets into clean tabular layouts (TSV, Excel).

## Supported Environments

- **Architectures**: `x86_64` (amd64), `aarch64` (arm64)
- **Linux Distributions**: Debian, Ubuntu, Fedora, RedHat, openSUSE, and Arch Linux

## Example Usage

```json
"features": {
    "ghcr.io/andreassag/features/dataformat-cli:1": {}
}
```
